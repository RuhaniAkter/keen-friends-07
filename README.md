# 👥 Keen-friends-07

A web app that tracks and manages friendships, helping you remember when to call or text friends.

---

### 🚀 Key Features

- **📅 Interaction Timeline:** Shows a beautiful, step-by-step history of all calls, texts, and meetups.
- **🏷️ Alert Tags:** Automatically tags friends as Overdue, On-Track, or Almost Due based on last contact.
- **📊 Charts:** Displays a nice donut chart to visualize your text, call, and video interaction percentages.

---

### 🛠️ Technologies Used

- **Core:** React
- **Routing:** React Router DOM
- **Styling:** Tailwind CSS
- **Icons:** Lucide Icons
- **Analytics:** Pure SVG Charts
