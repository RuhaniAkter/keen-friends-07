1. Project Name: Keen-friends-07

2. Short Description: A web app that tracks and manages friendships, helping you remember when to call or text friends.

3. Technologies Used: React, React Router DOM, Tailwind CSS, Lucide Icons, and Pure SVG Charts.

4. 3 Key Features:

1.Interaction Timeline: Shows a beautiful, step-by-step history of all calls, texts, and meetups.

2.Alert Tags: Automatically tags friends as Overdue, On-Track, or Almost Due based on last contact.

3.Charts: Displays a nice donut chart to visualize your text, call, and video interaction percentages.
